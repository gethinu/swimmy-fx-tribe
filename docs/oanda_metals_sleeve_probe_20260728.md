**Question（オーナー）.** OANDA が 2026-08-03 から東京MT5 商品CFD に **XAUXAG（金/銀レシオ）・XPTUSD（プラチナ）・
XPDUSD（パラジウム）**（最小0.01lot・1lot=100・証拠金5%）を追加する。tribe の確定した問い —

## 0. Verdict up front（実測 — 3銘柄すべて NO。ただし NO の理由は銘柄ごとに違う）

| 銘柄 | データ健全性 | 2窓 protocol | 実測 RT コスト | 「足りない無相関スリーブ」になり得るか |
|---|---|---|---:|---|
| **XAUXAG**（再構成） | **使える**（検証済み・下記§2） | **0 forward-robust。摩擦ゼロでも 0** | 33.4 bp | **NO** |
| **XPTUSD** | **使えない**（2021-11 開始 ⇒ holdout 窓が空） | **実行不能**（holdout 全186config が 0 trades） | **54.7 bp** | **NO** |
| **XPDUSD** | **使えない**（2021-07 開始・**かつ実際に薄い**） | **実行不能** | **51.6 bp** | **NO** |

- **XPT は「穴だらけ」ではなく「短すぎる」。XPD は「短く、かつ薄い」。** XPT の取得範囲のスキーマは完全に健全
  （OHLC 自己整合 100%、重複 0、多日ギャップ 0、60s 率 98.96%）。問題は**上場開始が holdout 窓
  （2015-01-01..2021-01-01）より後**であること。XPT 初出 **2021-11**、XPD 初出 **2021-07**（前月は 404 で確認）。
  ⇒ 2窓 forward gate は**構造的に実行不能**。実際 holdout スキャンは 186 config すべてが **trades = 0**。
  **XPD はさらに独立した第2の欠陥**を持つ: padding 除去率 **44.34%**、連続分の **60s 率が 88.43% しかない**
  （>5分ギャップ 7,315 本、最大 608 分）＝ **イントラデイに実際の流動性の穴がある**。
  無料の代替イントラデイ源はディスク上に存在しない（bundle にあるのは D1 の PPLT ETF のみ = Rule-A 違反、
  パラジウムは D1 すら無い）。**ここで即停止した。**
- **そして Pt/Pd は「待てば使える」でもない。** 実測スプレッドは **XPT 2.666 $/oz（RT 54.7 bp）/
  XPD 3.508 $/oz（RT 51.6 bp、p90 は 66 bp）** ＝ **FX 基準（1.8 bp）の約 30 倍**。
  2d で唯一生き残っている MR-EUR/USD ですら FX コストの 1.5–2 倍で死ぬことを踏まえると、
  **データが揃う 2027-2028 年以降に再試行しても、このコスト水準では通らない公算が極めて高い**
  （摩擦ゼロ→実コストの PF gap は実測で XPT **−0.592** / XPD **−0.343**）。**保留ではなく実質的に閉じている。**
- **XAUXAG は健全に再構成でき、正直に採点して落ちた。** そして落ち方が決定的:
  **実コスト（33.4 bp RT）で 0、摩擦ゼロでも 0。** 最良の平均回帰
  `bb-XAUXAG-REVERSION-p20-d2.0-H1` は摩擦ゼロで **2窓とも CPCV pass-rate 0.60（＝CPCV は通る）**のに
  **PF 1.067 / 1.061 で honest floor 1.10 に届かない**。つまり
  **GSR の平均回帰は「実在するが小さい」。そして実コストで PF 1.067 → 0.318 に崩壊する。**
- **コスト感度が答えを閉じた。** 実コストの **1/10**（RT 3.34 bp ≒ FX 並みの細さ）に落としても PF は
  **0.957 / 0.925** で 1.0 すら割る。⇒ **OANDA が XAUXAG をどんなに細いスプレッドで出しても届かない。**
  「ネイティブ単一銘柄だから2レグ・コストを免れるかも」という唯一の希望は、数字で消えた。
- **相関の前提は正しかった（が救わない）。** 金属系リターンと既存3群の相関は**本当に低い**
  （日次 |ρ| ≤ 0.112、月次 |ρ| ≤ 0.220）。分散の理屈は健全。**だが実コストの Sharpe が負**なので、
  束に足すと合成 Sharpe は**下がる**。
- **算術（⑬ 角度1 の更新）:** 既存3群の base は再現できた（static 正規化で 1'R1=3.616、
  合成 **0.807** ＝ ⑬ の 0.805 と ±0.002）。そこに 4 本目を足して 0.95 に届くには
  **無相関で Sharpe ≥ 0.506**（causal 正規化なら ≥ 0.653）が要る。
  0.5 級を **+1 本で 0.947（帯の下端ぎりぎり）／+2 本で 1.070（帯の中）**。
  ⇒ ⑬ の「あと1〜2本」は**正しいが楽観側の端**であり、**安全に帯へ入るには実質2本**。
  **今回それを供給できた銘柄は 0 本。**

**総合: 新規3銘柄は、いずれも「足りない無相関スリーブ」にならない。単一栽培は deployment gate で依然不破。**

## 1. データ健全性（最優先ゲート）

### 1.1 取得方法 — RAW-FIRST（過去の ts 消失事故の教訓）

ネットワーク・ペイロードを**未パースのままバイト単位でディスクへ**書き、デコードは `raw/` を**読むだけ**の
別スクリプトが行う。`raw/` を消す・書き換えるコードは存在しない。無料公開エンドポイントのみ（$0）:

```
https://datafeed.dukascopy.com/datafeed/{SYM}/{yyyy}/{MM0}/{dd}/BID_candles_min_1.bi5   # MM0 は 0 始まり月
```

**シンボル文字列は推測せず、実測で確定した。** `XPTUSD` / `XPDUSD` は **404**。
正しいコードは **`XPTCMDUSD` / `XPDCMDUSD`**（`PLATINUMCMDUSD` 等も 404 を確認）。
`XAUUSD` / `XAGUSD` はそのまま 200。

### 1.2 decode chain の独立検証（ここが通らなければ全部 phantom）

金属トラック全体が 1 本の decode 連鎖（`.bi5` → LZMA → `>iiiiif` → フィールド順 → `/10^dec`）に乗っている。
連鎖が誤っていれば下流の数字は全部偽物になるので、**完全に独立な別ソース**と突き合わせた。
独立源が存在するのは XAUUSD だけ（bundle `data/ohlc_cache/xauusd_m15.parquet`、⑫ が使用）。

| 検証 | 結果 |
|---|---|
| フィールド順（OHLC 自己整合率で経験的に決定） | `t,O,C,L,H,V` = **1.0000** vs `t,O,H,L,C,V` = 0.093〜0.637 ⇒ **OCLH 採用**（4銘柄すべて 1.0000） |
| 価格スケール `dec` | 4銘柄とも **`dec=3`**（2024-06 で XAU 2355.77 / XAG 30.02 / XPT 996.12 / XPD 930.99 = 実勢と一致） |
| **クロスソース照合（公称 UTC）** | ret-corr **−0.035**、med 差 **$3.78** ⇒ **一旦 FAIL** |
| **オフセット走査で原因特定** | **−180 分**で ret-corr **+0.994834**、med 差 **$0.155（0.66 bp ≒ 金スプレッドの半分）** ⇒ **PASS** |

**結論2点。** (i) decode 連鎖は**独立ソースで検証済み**（ラベルのずれだけで、値は一致）。
(ii) **bundle の `xauusd_m15.parquet` は UTC ではなくブローカー時計（夏 UTC+3 = EET）に載っている。**
⑫ はこの parquet を使っており、当時「小さな TZ オフセットは無視できる」と開示していた通りだが、
**DST で変動するラベル**である点は本 run の新規発見。
⇒ **本 run は全レグを Dukascopy（単一 UTC 時計）から取る。**レシオの同時刻性が構造的に保証される。

### 1.4 XPT / XPD — **ここで停止した**（「無理に先へ進めない」）

**代替源の不在も確認した**（$0 の範囲で）: bundle 全 D1 257 ファイル中、プラチナは `pplt_d1_yf`（ETF・D1）のみ、
**パラジウムは D1 すら無い**。D1 を M1 スコアラーに食わせるのは ⑦/⑫ が名指しした **Rule-A phantom-PASS 違反**
なので使わない。イントラデイの金属は `ohlc_cache/xauusd_m15.parquet` だけ（＝金のみ）。

**さらに決定的: コストを実測したら、待っても届かないことが分かった。**

| 銘柄 | 実測中央スプレッド | 価格水準 | **RT** | vs FX(1.8bp) | selection 窓のみの密度 | 摩擦ゼロ→実コストの PF gap |

> 上の密度・PF gap 欄は **protocol PASS ではなく**、単一窓の参考値である（2 窓が無いので robust 判定は存在しない）。

> **保留ではなく、実質的に閉じた箱として扱うのが正直。**

## 2. XAUXAG 再構成の正直さ（basis / 同時刻性 / スケール / コスト）

OANDA はネイティブ単一 CFD として出すが**歴史が存在しない**ので、再構成するしかない。
再構成はこの種の作業で最も事故が起きる場所なので、失敗モードを 3 つとも数字で潰した。

### 2.1 同時刻性（basis の本体）

異なる瞬間にサンプルされた 2 レグから作ったレシオは**作り物**で、見かけの平均回帰の一部は
「2 つの時計がずれている」だけになる。本 run は**単一ソース・単一 UTC 時計**の M1 を
**timestamp で inner join** した ⇒ 全レシオ bar が**同一分**の 2 bar から作られる。

| | 値 |
|---|---:|
| XAU 行数 / XAG 行数 | 3,541,662 / 3,465,114 |
| **一致した分（採用）** | **3,464,035** |
| 同時刻性 yield | **XAU 分の 97.81% / XAG 分の 99.97%** |

（もし bundle の XAU parquet（UTC+3, DST 変動）と UTC の XAG を混ぜていたら、まさにこの誤りを踏んでいた。§1.2）

### 2.2 通貨基準とスケール（OANDA 契約との整合）

両レグとも **USD / トロイオンス**なので**レシオは無次元**、USD numeraire は約分される（FX クロス項は無い）。
再構成値を既知の GSR 実績と突合:

| | 2015 | 2016 | 2017 | 2018 | 2019 | 2020 | 2021 | 2022 | 2023 | 2024 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 再構成レシオ 年央値 | 74.0 | 72.5 | 74.9 | 80.4 | 85.7 | 86.9 | 71.3 | 83.4 | 83.5 | 85.3 |

全体レンジ **62.33 – 128.93**（中央値 79.19）。**最大値 128.93 が 2020年3月 COVID の GSR スパイク（実勢 ~125）を
捉えている**のが独立な妥当性確認になっている。

**OANDA 契約系との整合:** 1 lot = 100 ⇒ **1.0 レシオ点 = 100 USD/lot**。レシオ 80.1 で想定元本
**8,007 USD/lot**、証拠金 5% = **400 USD/lot**、最小 0.01 lot ⇒ **4.0 USD**。
スコアラーのスリッページは**レシオ点**で表現される（＝ OANDA の価格単位と同じ）。

### 2.3 合成 OHLC は保守側

`o=oa/ob`, `c=ca/cb`, `h=ha/lb`（最大上限）, `l=la/hb`（最大下限）。**レンジを過大評価**する ⇒ ATR が大きくなり
バリアが**広く・厳しく**なる。楽観方向には決してぶれない。⑪ `gen_relval_series.py` と同一規約。自己整合 100.0000%。

### 2.4 コスト — ここが結論を決めた

**フィード自身の ASK−BID から実測**（仮定ではない）。per-side slip = **フル中央スプレッド**
（⇒ RT = 2×スプレッド。⑫ の指数 CFD と同じ規約で、FX 2-pip ≒1.8 bp RT より保守側）:

| レグ | 中央スプレッド（＝採用 per-side slip） | 一致 traded 分 | RT @ サンプル中央価格 | RT @ 全期間平均価格 |
|---|---:|---:|---:|---:|
| XAUUSD | **0.292 $/oz** | 356,624 | 4.57 bp（px 1279） | **3.63 bp**（px 1608.5） |
| **XAGUSD** | **0.030 $/oz** | 208,406 | 36.26 bp（px 16.5） | **29.78 bp**（px 20.15） |

（**スコアラーに渡すのは価格単位の 0.292 / 0.030 そのもの**で、bp は解釈用。ASK サンプルは年をまたぐ抜き取りなので
中央価格がサンプル構成に依存する ⇒ 両方の基準を出す。以下のレシオ計算は**全期間平均価格**を使う。）

**銀が主犯。** 単独で FX（1.8 bp RT）の約 **17 倍**。レシオの 2 レグ含意コスト:

```
per-side slip = R * (sprd_XAU/XAU + sprd_XAG/XAG)
              = 80.073 * (0.292/1608.51 + 0.030/20.146) = 0.13377 レシオ点
round-trip    = 0.26755 レシオ点 = 33.41 bp
```

OANDA 自身の単一銘柄スプレッドは**上場前で不明**。レシオを建てるブローカーは両レグをヘッジせねばならないので
2 レグ値が**保守的な下限**。ただしこの不確実性は**§3.4 のコスト掃引で完全に無効化**した
（実コストの 1/10 でも通らないため、OANDA の実クォートが何であっても結論は動かない）。

## 3. 実コスト 2 窓 forward protocol の結果（gate・floor は一切不変）

窓は ⑨〜⑬ と同一: **SEL = OOS 2021-01-01..2025-01-01 ＋ CPCV 全史 / HOL = OOS・CPCV 2015-01-01..2021-01-01**。
金属データは **2025-01-01 で打ち切り**、既存 FX/UK100 群と**同一カレンダー**にした（新参だけ 1 年多く見ない）。
格子は ⑫ の汎用 **186 config**（31 core × 6 TF、H1–D1、MR/TREND/BREAKOUT バランス）。

### 3.1 ハーネス自己検証

**XAUUSD で ⑫ の金の負け（"metals = 0 at any cost"）を独立に再現した** — 別フィード（Dukascopy M1 vs bundle M15）、
