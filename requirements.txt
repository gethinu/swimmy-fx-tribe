# Swimmy — Python runtime dependencies for the ops box (.venv).
#
# Why this file exists: `portalocker` (pulled in by src/python/single_instance.py,
# which tools/data_keeper.py imports at module scope) was never declared anywhere
# machine-readable, so a fresh checkout started swimmy-data-keeper straight into
# ModuleNotFoundError. Every third-party import reachable from a systemd unit's
# ExecStart is listed below so the venv can be rebuilt without archaeology.
#
# Install:
#     .venv/bin/python3 -m pip install -r requirements.txt
#
# Versions in comments are what the ops box runs today (2026-08-17); they are the
# known-good reference, not a hard pin, so security updates are not blocked.
